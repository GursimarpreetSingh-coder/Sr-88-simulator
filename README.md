# Sr-88 Circular Rydberg Simulator

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://sr-88-simulator.onrender.com)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

An interactive, research-grade web application for simulating and analyzing **Strontium-88 circular Rydberg atoms**. Built for researchers, students, and quantum optics enthusiasts, this tool provides a unified interface for atomic structure visualization, Stark-Zeeman spectroscopy, Lindblad dynamics, and AI-assisted quantum physics computation.

**🔗 Live Demo:** [https://sr-88-simulator.onrender.com](https://sr-88-simulator.onrender.com)

## ✨ Features

- **🔬 Atomic Structure Browser:** Visualize Strontium-88 energy levels, quantum defects, and Rydberg series.
- **⚡ Stark-Zeeman Spectroscopy:** Analyze how external electric and magnetic fields shift and split energy levels.
- **🧪 Lindblad Dynamics Solver:** Simulate open quantum systems with decoherence (spontaneous emission, blackbody radiation).
- **🔮 Optical Tweezer & Interactions:** Model trapping potentials and Rydberg-Rydberg interactions.
- **🐍 Python Library Suite:** Explore and export ready-to-use Python code (NumPy, SciPy, QuTiP) for your simulations.
- **🤖 Physics Copilot:** Ask an AI-powered assistant for help with pulse design, STIRAP, and quantum control problems.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **AI Engine:** Google Gemini API (for the Physics Copilot)
- **Deployment:** Render
- **Physics Libraries:** QuTiP, NumPy, SciPy (used in Python code)
